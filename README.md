# Вывод КИЗ из оборота — Честный Знак

Автор: Александр Казанцев

Локальное веб-приложение для массового вывода кодов идентификации (КИЗ) из оборота через API «Честного знака». Тип документа — `LK_RECEIPT`, причина — дистанционная продажа.

Работает на **Windows** и **Linux**.

Лицензия: [MIT](LICENSE)

## Документация

- [Вывод из оборота (через API)](docs/12-vyvod-iz-oborota-api.md)
- [API Честный Знак — техническое описание](docs/15-api-chestny-znak.md)

## Требования

- **Python 3.11+**
- **КриптоПро CSP + сертификат ЭЦП** — обязателен для авторизации и подписи документов в API Честный Знак
- **openpyxl** — для чтения XLSX Wildberries и формирования отчёта (устанавливается автоматически)
- **Браузер** — для открытия UI (`http://127.0.0.1:5100`)

### Windows

- **Visual C++ Redistributable 2013** — для нативных модулей Python: https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist
- **КриптоПро CSP** — для ЭЦП: https://www.cryptopro.ru/products/csp

### Linux

```bash
sudo apt install python3-dev gcc
```

Для ЭЦП: установить **КриптоПро CSP Linux** и модуль `pycades`.

## Установка

### 1. Создать виртуальное окружение и установить зависимости

**Windows:**
```
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

**Linux / Mac:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск

```bash
python -m app.chestny.runner --port 5100
```

Откроется в браузере: http://127.0.0.1:5100

Приложение слушает только `127.0.0.1` и не принимает внешние подключения.

## Использование

1. Откройте `http://127.0.0.1:5100` в браузере.
2. Выберите профиль: **ИП Синявин** или **ИП Красикова**.
3. Настройте ИНН, отпечаток сертификата и FIAS (однократно).
4. Загрузите XLSX Wildberries с листом **«КИЗ»**.
5. Приложение покажет предпросмотр: сколько строк пройдут фильтр, сколько исключены и почему.
6. Подтвердите отправку — приложение сформирует пакеты `LK_RECEIPT`, подпишет и отправит в ЧЗ.
7. После завершения скачайте XLSX-отчёт со списком успешно выведенных КИЗ.
