# Документация Честный Знак

Проект содержит только текущий контур: локальное приложение для вывода КИЗ из оборота по XLSX Wildberries через API Честного Знака.

## Файлы

- `15-api-chestny-znak.md` - техническое описание авторизации, подписи и API ЧЗ.
- `LK_RECEIPT_CONTRACT.md` - контракт документа `LK_RECEIPT` и проверенные поля payload.

Старые инструкции по складам, SKU, сканированию, печати этикеток, синхронизации и прежнему `run.py` удалены из репозитория.
