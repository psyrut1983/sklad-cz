Продажи и возвраты Wildberries

Загрузите исходный XLSX за любой период. Повторные события проверяются по истории. Коды и сведения об операциях проверяются в Честном знаке перед отправкой.

Если один КИ встречается несколько раз, выберите одно актуальное событие. Дата из файла не заменяет проверку связи с последней продажей.

Данные для выбранных строк

Причина вывода: дистанционная продажа. Дата и стоимость берутся из каждой строки WB. Номер документа формируется приложением, наименование — «Отчёт о дистанционных продажах Wildberries». Продажи за разные даты разделяются автоматически.

Оплата определяется отдельно для каждого возврата: чек и ФН пустые — без оплаты, оба заполнены — после оплаты. Для оплаченного возврата номер чека и дата берутся из строки WB. Оба вида возврата могут входить в один документ.

После проверки ЧЗ заполните данные выбранных строк и нажмите «Предпросмотр документов». После успешной подготовки станет доступна отправка.

Выберите строки и заполните данные для предпросмотра документов.

История и сверка

История сохраняется после перезапуска. Обновление списка не отправляет документы повторно. Для проверки статуса нажмите «Сверить».
